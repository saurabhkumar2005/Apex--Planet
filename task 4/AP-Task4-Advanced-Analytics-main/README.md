# 📊 Task 4 - Advanced Analytics & Statistical Modeling

## ApexPlanet Data Analytics Internship

### 📌 Project Overview

This project demonstrates statistical analysis, customer segmentation, and predictive modeling using Python on a cleaned ecommerce dataset.

---

## 🎯 Objectives

- Perform Descriptive Statistics
- Perform Hypothesis Testing
- Calculate Confidence Intervals
- Perform Customer Segmentation using K-Means Clustering
- Build a Basic Predictive Model using Linear Regression
- Generate Business Insights
