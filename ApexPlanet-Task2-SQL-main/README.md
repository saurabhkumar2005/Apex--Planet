# ApexPlanet Internship - Task 2: SQL for Data Extraction and Analysis

## 📌 Project Overview
This project demonstrates how to use SQL for data extraction and analysis using SQLite and Python. The ecommerce dataset is stored in a SQLite database and analyzed using SQL queries integrated with Python.

## 🛠️ Technologies Used
- Python
- SQLite
- SQLAlchemy
- Pandas
- VS Code

## 📊 Business Questions
1. Top 5 Most Expensive Products
2. Category-wise Total Products
3. Average Price by Category
4. Top 5 Highest Selling Products
5. Top 5 Highest Rated Products
6. Total Units Sold by Category
7. Products Out of Stock
8. Products with Rating Greater Than 4
9. Highest Price by Category
10. Total Revenue by Category

## ▶️ How to Run

1. Create a virtual environment.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Open the Jupyter Notebook:

```
notebooks/sql_python_integration.ipynb
```

4. Run all notebook cells.
